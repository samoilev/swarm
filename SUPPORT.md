# Support

## Where to ask

[GitHub Issues](https://github.com/samoilev/swarm/issues) is the only support channel.
There is no email support, forum, or chat.

Search existing issues first — someone may have hit the same thing.

- **Something is broken** → open a bug report.
- **Something is missing** → open a feature request.
- **A security problem** → do not open an issue. See [SECURITY.md](SECURITY.md).

## What is not supported

**Installation.** Swarm publishes no binaries. You build it from source; see the
[README](README.md). The DMG files attached to older releases are unsigned legacy
artifacts, kept for history only — they are not supported downloads, and questions
about them can't be answered.

**Your data.** Nobody but you can see your trees, so recovering a lost tree is
something only you can do. Swarm keeps the last 50 GEDCOM revisions under
`<Tree>/.Swarm/History/` and deleted files under `<Tree>/.Swarm/Trash/` for 30 days.
Look there first.

**Genealogy questions.** Swarm is a tool for recording research, not a research
service.

## Response times

This is a single-maintainer hobby project. Issues are read, but replies can take a
while and not every request will be built.
